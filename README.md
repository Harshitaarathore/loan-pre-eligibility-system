# 🏦 Loan Pre-Eligibility Prediction System

## 📌 Overview

This project is a Machine Learning-based system that predicts whether a user is eligible for a loan based on financial and personal attributes. It automates the initial screening process, helping reduce manual effort and improve decision-making speed.

---

## 🎯 Objectives

* Analyze user financial data
* Build a predictive model for loan eligibility
* Automate the loan pre-screening process
* Provide quick and data-driven predictions

---

## ⚙️ Features

* Data cleaning and preprocessing
* Exploratory Data Analysis (EDA)
* Feature engineering
* Machine Learning model training
* Organized and modular project structure

---

## 🛠️ Tech Stack

* **Language:** Python
* **Libraries:** Pandas, NumPy, Scikit-learn
* **Tools:** Jupyter Notebook, VS Code

---

## 📁 Project Structure

```
ML_LOAN_PRE_ELIGIBILITY/
│── app/            # Application-related files
│── src/            # Core source code
│── notebooks/      # Jupyter notebooks (EDA & experiments)
│── data_clean/     # Cleaned dataset
│── report/         # Project documentation/report
```

---

## 🚀 How to Run the Project

1. **Clone the repository**

```
git clone https://github.com/Harshitaarathore/loan-pre-eligibility-system.git
```

2. **Navigate to project folder**

```
cd loan-pre-eligibility-system
```

3. **Install required libraries**

```
pip install -r requirements.txt
```

4. **Run the project**

* Open notebooks in Jupyter Notebook
* OR run main Python files from `src/` or `app/`

---

## 📊 Output

The system predicts whether a user is eligible for a loan based on input features like income, credit history, and other financial attributes.
